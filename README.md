# Terraform AWS Infrastructure 🚀

This repository contains **Terraform configurations** for provisioning and managing AWS cloud resources. It follows **Infrastructure as Code (IaC)** best practices to ensure scalable, reproducible, and automated cloud deployments.

---

## 🌟 Features

✅ **Automated AWS Infrastructure Provisioning**  
✅ **Modular Terraform Code for Reusability**  
✅ **Supports AWS Services like EC2, S3, IAM**  
✅ **State Management using Remote Backends**  
✅ **Secure IAM Policies and Role Assignments**  
✅ **Scalable and Reproducible Cloud Deployment**  

---

## 📌 Prerequisites

Before using this Terraform setup, ensure you have:

- **Terraform Installed** → [Download Terraform](https://developer.hashicorp.com/terraform/tutorials/aws-get-started/install-cli)
- **AWS Account** → [Create an AWS Account](https://aws.amazon.com/)
- **AWS CLI Configured** → [Configure AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/cli-configure-quickstart.html)
